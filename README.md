# 卫星轨道可视化 · Satellite Orbit Viewer

一个开箱即用的纯前端三维卫星轨道可视化页面。使用真实 TLE 数据，**按你电脑上的本地时间**实时推算每颗卫星的位置，点击卫星即可放大并锁定跟随，同时用高亮光锥显示它此刻的拍摄范围。

> 数据精度仅供演示与观赏，请勿用于任何实际任务。

更新记录见 [CHANGELOG.md](CHANGELOG.md) 与 [Releases 更新公告](https://github.com/rmysjmzg987/rmysjmzg-personal-storage/releases)，当前版本 **v0.4.0**。

## 功能亮点

- **真实轨道数据**：内置 18 颗预置卫星，覆盖 9 类典型轨道——赤道低轨、极地轨道、太阳同步、低地球轨道、中地球轨道、倾斜同步、地球静止、大椭圆（Molniya 型）、逆行轨道。
- **点击锁定跟随**：点任意卫星光点，或直接点它的轨道线，相机立刻推近到「卫星在上、地球在下」的取景；再点「解除锁定」返回全局视角。
- **两种锁定视角**：按 `V` 或点详情卡上的「视角」按钮，可在**俯视**（相机在卫星本地天顶，卫星居中、地球在下）与**正视**（以拍摄光锥中点为中心水平侧视）之间切换，极轨与静止卫星都有一套合适的机位。
- **锁定时的手感与全局一致**：左键拖拽绕当前视角中心旋转（中心就是移动中的卫星），右键拖拽平移视角中心，滚轮缩放；俯视与正视都能自由缩放，缩放倍率不会被轨道高度或取景模式「拉回」；画面朝向按「北朝上」平滑回正，掠过极点不会翻转。
- **底部搜索栏**：页面底部常驻搜索框（按 `/` 聚焦），输入中文名、英文原名或 NORAD 编号都能实时匹配——中文界面下敲 `sentinel`、`landsat`、`iss` 一样能搜到；回车或点击结果立刻把该卫星加进场景并锁定跟随。
- **轨道管理**：弹窗新增「管理」页，列出当前画面上的每一颗卫星，可以逐颗移除（预制卫星同样可以移除），也可以一键「恢复默认」或「全部移除」。
- **拍摄范围光锥**：锁定或悬停卫星时，从卫星射向地面的视场光锥 + 地面覆盖圈会随卫星移动；落在拍摄范围里的城市名变金色并脉冲，刚被光锥扫过（还没进画面）的城市名留一段暖色余辉。
- **卫星详情卡**：轨道类型（带圆圈感叹号悬停说明）、实时高度、速度、周期、倾角、偏心率、星下点经纬度、视场角与简介。
- **轨道类型速查**：鼠标停在轨道类型右侧的 ⓘ 上会弹出该类轨道的通俗解释；详情卡在鼠标停留期间冻结刷新，数值不会跳动。
- **自由添加卫星**：
  - 粘贴 TLE（2 行或 3 行，可从 [CelesTrak](https://celestrak.org/NORAD/elements/) 复制）；
  - 用轨道根数表单生成（近地点高度、偏心率、倾角、RAAN、近地点幅角、平近点角），内置 6 个快速模板；
  - 从内置卫星库挑选 **180 颗**备选真实卫星，分为遥感影像、气象、载人航天、通信中继、导航、科学探测、大椭圆与特殊七大类，列表可滚动、可搜索（Landsat 8、Terra、Aqua、Aura、Sentinel-1/2/3/5P/6、WorldView、RADARSAT、ALOS、高分、资源、NOAA、风云、GOES、向日葵、流星、MetOp、北斗、GPS、伽利略、格洛纳斯、准天顶、铱星、一网、星链、O3B、Inmarsat、Intelsat、TDRS、哈勃、XMM-Newton、钱德拉、慧眼、天宫、神舟、子午线、闪电……）。
- **本地保存与迁移**：自定义卫星和启用的库卫星存在浏览器 localStorage，可随时「导出 / 导入」JSON 备份或分享。
- **中英文切换**：界面、城市名、卫星名、轨道类型说明全部双语。
- **时间控制**：×1 / ×10 / ×60 / ×600 倍率，可暂停、一键回到本机当前时间。
- **图层开关**：拍摄范围、经纬网格、轨道线可独立开关。
- **气象云图模式（v0.4 新增）**：顶栏一键在「卫星轨道 / 气象云图」之间切换（快捷键 `M`，也可用 `?mode=weather` 直达）。气象模式把地球换成一层半透明云壳——取自 NASA 每日全球真彩卫星影像并**只保留云**，没有云的地方完全透明；城市名右侧显示 Open-Meteo 的实时天气图标，悬停可看天气状况、气温、风速与降水；右侧栏还能一键叠加显示 10 颗主力在轨气象卫星（GOES / 向日葵 / 风云 / Meteosat / NOAA）。

## 快速开始

### 方式一：直接在线用（推荐，零安装）

用浏览器打开 <https://rmysjmzg987.github.io/rmysjmzg-personal-storage/> 即可，什么都不用装。

> 仓库里带好了自动部署工作流 `.github/workflows/deploy.yml`：每次推送到 `main` 都会重新构建并发布，本仓库已经开启，直接访问即可。
> 如果你是 **fork 或克隆到自己的仓库**，需要先在 Settings → Pages → Source 里选 “GitHub Actions”，否则地址会一直是 404。

### 方式二：下载到本地跑（离线用、或者想改代码）

需要 **Node.js 20.19+ 或 22.12+**（Vite 8 的要求；Node 18 会在启动时直接报错）。

```bash
git clone https://github.com/rmysjmzg987/rmysjmzg-personal-storage.git
cd rmysjmzg-personal-storage
npm install
npm run dev        # Vite 会打印本地地址，浏览器打开它即可
```

### 方式三：打包成静态站点，丢到任意托管

```bash
npm run build      # 类型检查 + 打包到 dist/
npm run preview    # 先本地预览一下 dist/ 的效果
```

`dist/` 是一份纯静态产物（构建用相对路径，放在子目录里也能跑），上传到 GitHub Pages、Vercel、Netlify、nginx、对象存储都可以。

> 页面需要 WebGL 和 http(s) 环境：直接双击 `dist/index.html`（`file://` 协议）浏览器会拦掉数据文件的加载，必须走一个本地或线上的静态服务器。

### 其他命令

```bash
npm test               # 单元测试（Vitest）
npm run lint           # ESLint
npm run fetch:tle      # 从 CelesTrak 刷新 TLE 快照（可选，需联网）
npm run fetch:textures # 抓取 NASA 高清贴图母版（可选，仓库内已带缩放版）
```

## 气象云图模式

顶栏的「气象云图」把整页切成气象视图，和卫星轨道模式互不干扰：

- **云壳**：地球外挂一层半径 ×1.012 的球壳，贴图是 NASA 的全球真彩卫星影像；片元着色器按「亮度高 + 饱和度低 + 黄调弱」把云提取出来，海洋、沙漠、植被都判为透明，于是只剩云悬在地球上。云壳挂在地球组里，跟着自转走；影像只有白天数据，所以夜面自动不显示云（与地球夜灯面一致）。
- **城市天气**：102 座城市按 Open-Meteo 批量取当前天气，WMO 天气码映射为内联 SVG 图标（晴/多云按当地昼夜换成太阳或月亮），悬停出气泡。
- **专业气象卫星**：右侧「气象卫星」开关只显示主力在轨气象星（GOES-16/18、向日葵 8/9、风云四号 B、Meteosat-12、风云三号 D/G、NOAA-20/21），这份名单独立于你在轨道模式里对卫星的增删，切回来不会改动你的卫星清单。
- **时间语义**：云图和天气都是"此刻"的数据，所以进气象模式会把模拟时钟停在现在（退出时还原原来的播放状态与倍率）。

关于"实时"的实话：免费、免 key、且允许浏览器直连（CORS）的**全球**实时云图目前不存在——GOES、向日葵这些静止卫星的可见光云图只有日面、夜里全黑，而且非洲与欧洲有大片覆盖缝（实测结论）。因此本页采用的是 NASA 的**每日**全球真彩影像（VIIRS / NOAA-20，宽幅扫描，全球拼接后没有 MODIS 那种楔形轨道缝），页面会如实标注"云图时间"。城市天气则是实时的，默认在进入气象模式时拉一次，30 分钟以上会重新拉，也可以随时点「刷新数据」。

## 添加自己的卫星

1. 打开「添加卫星」弹窗。
2. 三种方式任选其一：
   - **卫星库**：搜索或滚动浏览七大类共 180 颗，点「添加」；预设的 18 颗默认显示，其余可自由增删。
   - **粘贴 TLE**：从 CelesTrak 等站点复制两行或三行 TLE 粘贴即可，识别成功会显示 NORAD 编号。
   - **轨道根数**：填近地点高度、偏心率、倾角等参数，或点一个模板（赤道低轨 / 极轨 / 太阳同步 / 地球静止 / 大椭圆 / 逆行）后微调。
3. 视场角（FOV）决定拍摄范围光锥的宽度，可按需调整。
4. 自定义卫星会自动分配 90000 以上的展示编号，并保存在本机浏览器里。

想清掉已经加进来的卫星，切到弹窗的「管理」页：每颗在画面上的卫星都有「移除」按钮（预制卫星也能移除），底部还有「恢复默认」（回到只显示 18 颗预置卫星）与「全部移除」。移除只是从画面隐藏，随时可以在卫星库里加回来。

导出的 JSON 包含所有自定义卫星与启用的库卫星，可在其他电脑或浏览器上导入还原。

## 数据来源

- **TLE（两行轨道根数）**：快照文件 `public/data/catalog.json`，取自 [CelesTrak](https://celestrak.org/)（快照日期见页面左下角）。
- **位置计算**：浏览器本地使用 SGP4（[satellite.js](https://github.com/shashwatak/satellite-js)）按设备当前时间推算，因此同一时刻在不同设备上结果一致，随时间连续变化。
- **城市坐标**：`public/data/cities.json`，102 座代表性城市。
- **地球贴图**：昼面为 NASA Blue Marble 地形/海深版（8192×4096），夜面为 NASA VIIRS 2012 夜间灯光（8192×4096），均为等距圆柱投影，与自转角和城市坐标严格配准；渲染时叠加了按相机距离衰减的地形凹凸光照与海面高光，贴地看有立体感、远看又不会发花。
- **轨道分类规则**：见 `src/orbit/classify.ts`，按偏心率、周期、倾角与近地点高度自上而下判定。
- **气象云图**：NASA GIBS / Worldview Snapshot 接口（`wvs.earthdata.nasa.gov`，CORS `*`、无需 key），图层 `VIIRS_NOAA20_CorrectedReflectance_TrueColor`，默认取 UTC 昨天，没有数据自动往前回溯一天。
- **城市天气**：Open-Meteo 免费接口（`api.open-meteo.com`，CORS `*`、无需 key），一次请求可带多个坐标，102 座城市拆成 3 批并发拉取。

重新抓取 TLE（需要联网）：

```bash
npm run fetch:tle        # 重新抓取目录中的卫星 TLE
npm run fetch:textures   # 重新下载地球贴图
```

## 技术栈

TypeScript + Vite + three.js + satellite.js（SGP4）+ 原生 DOM/CSS，无前端框架。测试使用 Vitest。

几个实现要点：

- 卫星位置与速度全部在浏览器端实时计算，页面不含任何预烘焙动画。
- 拍摄范围光锥的地面覆盖半径使用解析解 `λ = asin(r·sinα / R) − α`，并有单元测试对照。
- 相机锁定把视线对齐卫星的本地天顶，得到「卫星在上、地球在下」的取景；画面上方向按「北朝上」平滑跟随，进入极区时退化为平行传输，避免镜头翻转或万向节卡死。
- 锁定期间相机完全由 `src/core/followCamera.ts` 接管（OrbitControls 停用），左键旋转、右键平移、滚轮缩放都基于内部角度状态计算，连续拖拽不会出现方向跳变；「正视」模式的取景中心是拍摄光锥中点，取景距离按卫星高度自适应。滚轮缩放的实现是把倍率叠在本位取景距离上（再夹在绝对上下限内），所以换轨道、换视角都不会把用户调好的缩放拉回去。
- 搜索匹配是纯函数 `matchSatellite()`：本地化名称前缀 > 名称包含 > 英文/中文原名（别名）> NORAD 编号 > 轨道分组名，别名命中时仍然显示本地化名称，并在副标题里标出命中的写法。
- 星空被当作无限远背景：星空球每帧跟随相机位置，所以无论放大到贴地还是缩到几万公里，背景星点都不会被「缩掉」。
- 轨道线拾取在屏幕空间做点到线段距离判定，所以不必先精确找到卫星光点也能点线锁定（地球背面的线段会被剔除）。
- 帧率低于阈值时自动降级画质（星空数量、像素比、大气效果）。

## 已知限制

- TLE 是快照数据，日期越久远位置误差越大；页面不自动联网更新。
- 拍摄范围按圆视场近似，未模拟侧摆、扫描条带与真实传感器幅宽。
- 城市高亮分两档：金色脉冲＝落在几何覆盖圈内（判定圈放宽到 1.6 倍，避免城市贴着边缘反复闪）；暖色余辉＝被外扩后的「掠过圈」扫过，该圈半径有 8°（约 890 km）下限，否则窄视场卫星（例如 Landsat 的 15°）一天也扫不到几座城市。余辉按模拟时间保留 150 秒，高速推进时间时也能看清扫过的轨迹。内置城市只有 102 座，判定半径与城市密度不匹配时仍会漏掉小城市。
- 地球贴图取自 NASA 公开影像（8192×4096），继续放大到贴地级别仍会发虚——想要更锐利可以自己下载 21600×10800 母版替换 `public/textures/` 下的两张图片（`npm run fetch:textures` 抓的就是母版，文件较大，仓库里放的是缩放后的版本）。
- 云壳用的是 NASA **每日**全球真彩拼接影像，不是实时云图，而且只有日面有数据（免费、免 key、允许浏览器直连的全球实时云图目前不存在，详见上文「气象云图模式」）。云提取是对真彩像素的启发式判据，明亮的沙漠或雪地被误判成薄云属于已知误差。气象卫星叠加名单固定为 10 颗主力在轨气象星，不随你在轨道模式里的增删变化。
